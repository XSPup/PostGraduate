# PostGraduate 研究生工作区

这是一个按“收集 → 项目/课程学习 → 阅读与写作 → 长期笔记 → 备份”组织的研究生学习与研究仓库。现阶段以安全、渐进式整理为原则：已有材料不做批量改名或搬迁，新内容按下表归档。

## 目录地图

| 目录 | 用途 | 建议放入 |
|---|---|---|
| `00_Inbox_临时收集/` | 尚未分类的临时入口 | 新收到、待判断归属的文件；应定期清空 |
| `01_Projects_项目/` | 有明确目标和产出的项目 | 项目代码、实验、项目报告、专项学习工作区 |
| `02_Papers_读论文/` | 论文与阅读材料 | 按 `AI/`、`Method/`、`Network/` 等主题归档的论文 |
| `03_Writing_写论文/` | 正在写作的学术内容 | 论文草稿、图表源文件、投稿材料 |
| `04_Courses_课程/` | 课程材料 | 课件、作业、课程笔记和课程项目 |
| `05_Notes_笔记/` | 跨项目的长期知识 | 可复用概念笔记、方法总结、索引 |
| `99_Backup_备份导出/` | 明确的备份与导出物 | 阶段性快照、外部工具导出；不作为日常工作区 |

仓库根目录的 `.obsidian/` 是 Obsidian 工作区配置；`tmp/` 用于临时处理产物，不应继续堆放长期材料。

## 重点项目

`01_Projects_项目/MyDeepLearning-main/` 是机器学习与深度学习主学习工作区，包含：

- `LearningNotes/`：长期课程笔记和可复用学习材料。
- `LearningNotes/d2l-pytorch-notebooks/`：经过筛选并纳入 Git 管理的《动手学深度学习》PyTorch notebook 套件。
- `MyHandwrittenNotebookwithLIMU/`：个人跟学、手写 notebook。
- `ResearchPlanning/`：学习路线与研究方向规划。
- `ScratchNotebooks/`、`ScratchScripts/`、`data/`：本地草稿、临时脚本和数据，不作为默认发布内容。

更细的说明见 `01_Projects_项目/MyDeepLearning-main/README.md`。

## 新增材料约定

1. 暂时不知道放哪的文件先进入 `00_Inbox_临时收集/`，不要直接堆在仓库根目录。
2. 有明确交付目标的内容放进 `01_Projects_项目/`；课程作业优先放进 `04_Courses_课程/`。
3. 原始论文放 `02_Papers_读论文/`，自己的论文草稿放 `03_Writing_写论文/`，不要混放。
4. 运行生成的模型、缓存、数据集、日志和 notebook checkpoint 不提交，必要时在对应项目的 `.gitignore` 中精确排除。
5. 提交前先执行 `git status --short`，只暂存本次工作涉及的明确路径；大文件在加入 Git 前先确认必要性。

## 暂不执行的整理建议

为避免破坏已有引用和个人工作流，当前不做下列批量变更：

- 清理或迁移根目录 `tmp/` 中现有预览文件；
- 统一历史项目、论文和报告的命名格式；
- 调整现有 `.obsidian/` 配置文件的跟踪策略；
- 重新分类 `01_Projects_项目/YY报告集合/` 内的历史交付材料。

这些项目适合在确认引用关系、备份和使用习惯后分批处理。
