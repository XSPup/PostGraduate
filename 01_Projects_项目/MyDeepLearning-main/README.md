# MyDeepLearning Workspace

这个目录用于保存机器学习、深度学习和未来网络 + AI 的本地学习材料。当前已经按用途整理为几个一级目录，避免所有项目和脚本混在根目录。

## Directory Layout

| 目录 | 用途 |
|---|---|
| `OpenSourceProjectPractice/` | 开源项目复现和实践项目，包含鸢尾花、线性回归等可运行练习 |
| `LearningNotes/` | 课程笔记、Andrew Ng 课程 notebook、神经网络基础记录 |
| `ResearchPlanning/` | 学习路线、未来网络 + AI GitHub 项目筛选、研究方向规划 |
| `ScratchScripts/` | 临时或单文件实验脚本 |
| `ScratchNotebooks/` | 临时 notebook 草稿 |
| `.venv/` | 当前工作区 Python 虚拟环境，不移动、不手动改名 |
| `.obsidian/` | Obsidian 配置目录，不移动 |

## 整理原则

- 新的开源复现项目统一放到 `OpenSourceProjectPractice/`。
- 课程材料和长期笔记放到 `LearningNotes/`。
- 研究方向、论文项目、GitHub 选题材料放到 `ResearchPlanning/`。
- 临时脚本和临时 notebook 不直接堆在根目录，分别放到 `ScratchScripts/` 和 `ScratchNotebooks/`。
- `.venv`、`.obsidian`、`.ipynb_checkpoints` 这类环境/工具目录保持原样。
