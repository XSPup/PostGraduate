目标：用尽量简单的 Python 代码手写 KNN，完成 Iris 鸢尾花分类。

当前文件：

- `iris_knn_from_scratch.py`：主脚本。先包含导包、读取数据、划分训练/测试集，KNN 算法部分留给自己手写。

运行方式：

```cmd
cd /d D:\MyDeepLearning\iris-knn-from-scratch
python iris_knn_from_scratch.py
```

建议实现顺序：

1. 写欧氏距离函数。
2. 写单个样本预测函数。
3. 写批量预测函数。
4. 写准确率计算函数。
