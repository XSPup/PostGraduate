一个神经元怎样算出预测值

先不要管反向传播。这里先看一件事：输入节点经过带权重的连线，进入一个神经元，神经元先算 z，再用 sigmoid 把 z 变成 0 到 1 之间的输出 a。

z = w1*x1 + w2*x2 + b
z = 2.00*1.00 + -2.00*0.00 + 0.00 = 2.00
a = sigmoid(z) = 1 / (1 + e^(-z)) = 0.88

怎么读这个输出

如果 a >= 0.5，就判断为 1；否则判断为 0。 1

调大正权重会让对应输入更支持输出 1；调成负权重会让对应输入更压低输出。偏置 b 像整体开关，会把 z 整体往上或往下推。
