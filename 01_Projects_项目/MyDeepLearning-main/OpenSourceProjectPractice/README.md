## Naming

后续新项目建议使用英文小写短横线命名，例如：

```text
network-traffic-prediction/
oran-anomaly-detection/
gnn-routing-digital-twin/
```

每个项目至少保留：

- `README.md`
- `requirements.txt` 或环境说明
- 可运行脚本或 notebook
- 数据来源说明
- 输出结果目录或实验记录
